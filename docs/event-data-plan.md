# イベントデータ運用計画

## 目的

二戸市内のイベントを、開催日・カテゴリ・地区・会場から探せる状態にし、同じデータをカレンダー、一覧、Googleマップで表示します。

「すべてのイベント」を一度に集め切るのではなく、情報源ごとの取得状況と確認日を残し、対象範囲を段階的に広げます。

## 取得優先順位

| 優先度 | 情報源 | 主な対象 | 確認頻度 | 取得方法 |
|---|---|---|---|---|
| 1 | 二戸市観光ツーリズム協会「催事」 | 祭り、観光、体験、マルシェ | 毎日 | 公開ページの差分取得 |
| 1 | 二戸市公式サイト | 行政、市民向け講座、募集 | 毎日 | 新着情報・イベントページの差分取得 |
| 1 | 広報にのへ | 健康、子育て、文化、地域行事 | 月2回 | PDF公開時に抽出し、人が確認 |
| 2 | 二戸市シビックセンター | 展示、科学、文化イベント | 週1回 | 施設カレンダーの差分取得 |
| 2 | 二戸市民文化会館 | 公演、発表会、展示 | 週1回 | 月間催事予定の差分取得 |
| 2 | にこランス・市内公共施設 | サークル、交流、地域行事 | 週1回 | 利用予定表のうち一般参加可能な催しを確認 |
| 2 | なにゃーと・二戸青果市場 | よ市、物産展、日曜朝市 | 週1回 | 施設・市公式・主催者SNSを照合 |
| 3 | 主催者SNS | 個人店、マルシェ、ワークショップ | 毎日 | X・Instagram・Facebookの公開投稿を候補化 |
| 3 | 地域ブログ・個人発信 | 小規模な催し、販売会、地域活動 | 毎日 | 発見元として記録し、主催者へ確認 |
| 3 | 主催者投稿 | 商店、町内会、学校、団体の催し | 随時 | 共通投稿フォーム + 編集部承認 |

## 情報源の表示

- `official`: 市、観光協会、公共施設などの公式情報
- `organizer`: 主催団体、店舗、会場が直接発信した情報
- `community`: 個人SNSや地域ブログなどの地域発信

地域発信だけで日時を確定せず、主催者発信との照合または直接確認後に公開します。ページ上でも情報源の種類を表示します。

## 必須データ

公開前に次の項目を確認します。

- イベント名
- 開始・終了日時
- 会場名と住所
- 緯度・経度
- カテゴリと地区
- 料金と申込要否
- 主催者・問い合わせ先
- 一次情報のURL
- 最終確認日

## 重複と更新のルール

1. イベント名、開催日、会場の3項目が一致するものを重複候補とします。
2. 同じイベントが複数の情報源にある場合、主催者または行政の一次情報を優先します。
3. 内容変更・延期・中止を確認した場合は、一覧から削除せず状態を明示します。
4. 開催後のイベントは通常表示から外し、将来のアーカイブに移します。
5. 自動取得した内容は、公開前に日時・会場・出典を人が確認します。

## Googleマップ表示

- `NEXT_PUBLIC_GOOGLE_MAPS_API_KEY` がある場合、絞り込み結果を複数ピンで同時表示します。
- APIキーがない場合、会場の概略位置とGoogleマップで開くリンクを表示します。
- 各イベントには、Googleマップアプリ／サイトで直接開くリンクを常に表示します。
- 緯度経度は住所検索だけに依存せず、会場マスタとして人が確認した値を保持します。
