Walkerplus、個人SNS、地域ブログは「発見元」として扱い、主催者情報との照合または直接確認を行ってから公開します。発見元と一次情報が異なる場合は、イベントカードに両方のリンクを表示します。

詳しい取得順序と確認ルールは [event-data-plan.md](event-data-plan.md) を参照してください。

## 注意事項

- 「推計値」と表記されたデータは、公式統計を元に編集部が計算・加工したものです
- 掲載値は特記なき限り、最終更新時点の最新値です
- 出典元での修正・改訂により、実際の数値と異なる場合があります
